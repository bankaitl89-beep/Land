# Prompta aut perire — лендинг онлайн-курса

Продающий одностраничник курса «ИИ в работе для не-программистов». Цель страницы одна —
заявка (имя + почта + выбранный тариф), которая уходит в Telegram. Оплаты на странице нет:
дальше с человеком связывается живой менеджер.

Дефолтный SITE_URL — `prompta-aut-perire.vercel.app`; для прода задавать `NEXT_PUBLIC_SITE_URL`,
иначе canonical, hreflang, sitemap и OG будут указывать на vercel. (growthbureau.ai — другой
проект владельца, к этому репозиторию отношения не имеет.)

## Стек

Next.js 15.5 (App Router) + React 19 + TypeScript. Ноль runtime-зависимостей кроме next/react.
Без Tailwind — весь стиль в `app/globals.css` (~69 КБ). Шрифты свои в `public/fonts`
(Unbounded — заголовки, Manrope — текст, JetBrains Mono), `app/fonts.css` генерит
`scripts/fetch-fonts.mjs`. Тёмная тема, themeColor `#06070b`.

## Структура

- `lib/content.ts` — ВЕСЬ текст страницы, 4 языка: `en`, `de`, `es`, `ru` (тип `Copy` = форма `en`,
  остальные языки обязаны совпадать по ключам). Правка текста = правка только этого файла.
- `lib/i18n.ts` — список языков, cookie `lang` (1 год), выбор по Accept-Language с учётом q, дефолт `en`.
- `middleware.ts` — только `/`: редирект на `/{lang}` (cookie → браузер).
- `app/[lang]/layout.tsx` — meta/OG/twitter/hreflang по языку, JSON-LD `Course` (Offer $150 USD).
- `app/[lang]/page.tsx` — рендерит `<Landing>`; `dynamicParams=false`, 4 статических пути.
- `app/api/lead/route.ts` — приёмник заявок для серверного режима (Node).
- `app/robots.ts`, `app/sitemap.ts` — `/api/` закрыт, sitemap по 4 языкам.
- `components/Landing.tsx` — вся страница, секции по порядку (ниже).
- `components/LeadForm.tsx` — форма; `NeuralField.tsx` — canvas-нейросеть на фоне (8 слоёв × 40
  нейронов, камера летит при скролле, на нейронах подписи задач из `field.tasks`);
  `AssemblyScene.tsx` — закреплённая сцена, 9 «умений» падают в стопку по скроллу;
  `PromptBuilder.tsx` — интерактив «впиши задачу → проблема / что вставить в чат / что придёт»;
  `PlatformMock.tsx` — макет платформы обучения; `Cursor.tsx` — кольцо за курсором (только pointer:fine);
  `useDepthEffects.ts` — reveal on scroll, подсветка, наклон карточек, счётчики, магнитные кнопки,
  `useTypewriter` для героя. Вся анимация аддитивна — без JS страница полная.
- `deploy/lead.php` + `lead.config.example.php` — приёмник для статического режима (PHP 8 + curl).
- `scripts/` — `build-static.mjs` (хенд-офф), `build-preview.mjs` (превью для дизайн-ревью),
  `check-telegram.mjs` (проверка бота), `make-og.mjs` (OG-картинки через Playwright, PNG закоммичены),
  `fetch-fonts.mjs`.
- `docs/` — маркетинговые материалы (не код), см. ниже.
- `.claude/skills/` — скилы Сердитова (исследование → продукт → конвертер) и ui-ux-pro-max.

## Продукт (суть оффера)

Онлайн-курс, 6 частей: 01 База, 02 Beginner, 03 Intermediate (как просить, заготовки, библиотека,
помощники), 04 Advanced (автоматизация, агенты, дашборды без кода), 05 Бонус 49 минут для
руководителей, 06 Что дальше (внедрение в команду). Следующая часть открывается только после сдачи
предыдущей; каждое задание на реальной работе ученика проверяет живой преподаватель. Без кода,
без дедлайнов. Итог — 9 «заготовок» (многоразовых промптов). Ключевая идея: не «спрашивать», а
«поручать» — дать 4 вещи: кто читает, откуда факты, в каком виде ответ, по чему понять, что годно.

Тарифы (одна программа, разница в сроке доступа и ведении), скидка ~50% на всех:
- `base` Базовый — $150 (было $299), доступ 4 месяца;
- `full` Постоянный — $250 (было $499), доступ навсегда;
- `mentor` С личным ведением — $500 (было $999), SOLD OUT, в форме выбрать нельзя.

Позиция честности: отзывов нет, пока нет настоящих (`docs/collect-testimonials.md`); гарантий и
возврата не обещают; есть блок «кому не подойдёт».

## Поток заявки

Форма: радио тарифа (дефолт `base`, кнопка карточки только предвыбирает) + имя (≥2) + почта
(regex) + скрытый honeypot `company`. POST JSON:
`{name, email, lang, tier, tierName: "Базовый — $150", page: location.href, company, ...NEXT_PUBLIC_LEAD_EXTRA}`.

Endpoint выбирается в момент отправки: `window.LEAD_ENDPOINT` (из `config.js` рядом со страницей)
→ `NEXT_PUBLIC_LEAD_ENDPOINT` → `/api/lead`.

Два режима деплоя:
1. Сервер (Vercel / VPS `output: standalone`, `node server.js`): `/api/lead` → Telegram
   `sendMessage` (HTML, таймаут 10 с). Env: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
   Honeypot → фейковый 200. Rate limit 6/мин/IP в памяти процесса. Нет токена → 500.
   Telegram упал → 502 и строка `lead: UNDELIVERED` в лог для ручного восстановления.
2. Статика (`npm run static` → `dist/frontend` + `dist/backend` + `prompta-landing.zip`):
   страница одним самодостаточным файлом, middleware и API убираются, адрес приёмника правится
   одной строкой в `frontend/config.js`. Приёмник `lead.php`: СНАЧАЛА пишет JSON-строку в
   `leads.log` (с флагами `bot`/`no-name`/`bad-email`/`rate-limited`), потом решает; CORS по
   `origins`; без token/chat — просто лог, это штатно. Инструкция — `DEPLOY.md`, `deploy/README.md`.

`npm run preview` — `NEXT_EXPORT=1`, статичный экспорт для дизайн-ревью, форма неактивна,
`NEXT_PUBLIC_PREVIEW=1` включает переключение языка внутри одного файла.

## Известные несостыковки и риски

- `DEPLOY.md` пишет «три языка» — языков уже четыре (добавлен `de`).
- `docs/sostav-produkta.md`: «доступ не заканчивается» — противоречит тарифу Базовый (4 месяца).
- JSON-LD отдаёт один Offer $150, без двух других тарифов.
- Rate limit в `route.ts` — Map в памяти: на Vercel (несколько инстансов, холодные старты)
  почти не работает; на одном VPS — работает.
- `lead.php` доверяет `CF-Connecting-IP` / `X-Forwarded-For` без проверки — вне Cloudflare
  лимит обходится подменой заголовка.
- `route.ts` не пересылает `page` (UTM) в Telegram и не пишет тариф в `UNDELIVERED`; `lead.php` — пересылает.
- Непроверяемые заявления на странице: «500+ выпускников», «100% работ проверено», опыт
  преподавателя без имени — риск для модерации рекламы и доверия.
- `scripts/check-telegram.mjs` из песочницы не запускался (нет сети) — доставка в Telegram
  подтверждается только на реальном хосте.
