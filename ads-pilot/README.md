# Ads Pilot

Личный кабинет для Meta Ads: обзор, кампании, рейтинг креативов и агент, который читает статистику и предлагает изменения. Без подтверждения агент ничего не меняет, если не включён автопилот.

## Что умеет первая версия

- **Обзор** — расход, ROAS, CPA, конверсии с изменением к прошлому периоду, график, сигналы: выгорание креатива (CTR за 3 дня упал на 30%+), CPA группы выше цели, нет конверсий за вчера.
- **Кампании** — дерево кампания → группа → объявление, включение и выключение, дневной бюджет прямо в таблице, журнал изменений.
- **Рейтинг** — креативы, заголовки, группы, форматы; метка «Мало данных» по порогам из настроек.
- **Агент** — чаты, выбор модели (авто, Claude Opus/Sonnet/Haiku 5.5, DeepSeek, Grok, OpenAI, локальная через Ollama), режимы «Спрашивать» и «Автопилот», очередь подтверждений, память.
- **Права агента** — что можно делать самому, шаг изменения бюджета (±%), потолок суммарного дневного бюджета, защищённые кампании по метке в названии. Удаление запрещено всегда.
- **Настройки отчётов** — окно атрибуции (1/7 дней клик, 1 день просмотр) с пересчётом без повторной загрузки, валюта показа, целевое событие, цели и пороги.

## Запуск

Нужен Node.js 22.5+ (используется встроенный `node:sqlite`).

```bash
npm install
cp .env.example .env      # без токена Meta приложение работает на демо-данных
npm run build             # собрать интерфейс
npm start                 # http://127.0.0.1:8787
```

Разработка: `npm run dev:server` и `npm run dev:web` в двух терминалах (интерфейс на http://localhost:5173).

## Подключение Meta

1. В Meta for Developers создайте приложение типа Business и добавьте Marketing API.
2. В Business Manager создайте системного пользователя с доступом к кабинету и выпустите токен с правами `ads_read` и `ads_management`.
3. Впишите `META_ACCESS_TOKEN` и `META_AD_ACCOUNT_ID` в `.env` и перезапустите.

Синхронизация: при старте и раз в час, последние 90 полных дней, статистика по объявлениям по дням с разбивкой по окнам `1d_click`, `7d_click`, `1d_view`.

## Как устроено

- `shared/` — общая логика: расчёт метрик, сигналы, рейтинг, инструменты агента и проверка прав. Одна и та же для сервера и для превью.
- `server/` — Hono + SQLite: хранение, клиент Graph API, агентный цикл (Claude через `@anthropic-ai/sdk`, остальные через OpenAI-совместимый API).
- `web/` — React-интерфейс.
- `npm run build:static` — превью одним HTML-файлом на демо-данных, без сервера.

## Ограничения и что проверить

- Нет авторизации, если не задан `APP_PASSWORD`. По умолчанию сервер слушает только `127.0.0.1`.
- Ключи, введённые в интерфейсе, хранятся в SQLite открытым текстом — это приемлемо для личного сервера, но не для общего.
- Бюджеты Meta хранит в минимальных единицах валюты; список валют без копеек в `server/meta.ts` стоит сверить с документацией Marketing API.
- Стоимость ответов считается только для Claude по прайс-листу; при срабатывании запасной модели (fallback) сумма приблизительная.
- DeepSeek через официальный API обрабатывает данные на серверах в Китае.
- Пока не сделаны: студия креативов, массовый запуск, конструктор, аудитории, библиотека, автоправила по расписанию.
