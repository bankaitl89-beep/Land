# Деплой — Prompta aut perire

Лендинг одностраничный, три языка в одном файле, язык определяется по браузеру.
Форма собирает имя и почту.

Две независимые части:

| папка | что это | куда |
|---|---|---|
| `frontend/` | сам лендинг, статика | в трекер / на любой хостинг |
| `backend/` | приёмник заявок, один PHP-файл | на хостинг с PHP |
| `source/` | исходники проекта | **не нужны для деплоя** |

Связаны одной строкой: во `frontend/config.js` написан адрес `lead.php`.

---

## 1. Приёмник — 5 минут

Нужен PHP 8 с `curl`. Больше ничего: ни composer, ни базы.

1. Залей `backend/lead.php` и `backend/lead.config.example.php` на хостинг.
2. Переименуй `lead.config.example.php` → `lead.config.php`.
3. Открой его и впиши два значения:

   ```php
   'token' => 'токен от @BotFather',
   'chat'  => '7969340046',
   ```

   Оставишь пустыми — заявки будут просто писаться в лог, без уведомлений.
   Это рабочий режим, не поломка.

4. Проверь, что файл отвечает:

   ```
   curl -X POST https://ваш-домен/lead.php \
     -H 'content-type: application/json' \
     -d '{"name":"Проверка","email":"test@example.com","lang":"ru"}'
   ```

   Ждём `{"ok":true}` и строку в `leads.log` рядом с `lead.php`.

Папке нужны права на запись — туда пишется `leads.log`.

## 2. Лендинг — 5 минут

1. Залей содержимое `frontend/` куда отдаётся статика. Внутри всё по
   относительным путям, поэтому работает из любой подпапки.
2. Открой `config.js` и замени адрес на свой:

   ```js
   window.LEAD_ENDPOINT = "https://ваш-домен/lead.php";
   ```

   Это единственная правка. Пересобирать ничего не нужно.

3. Открой страницу, пролистай до формы, отправь тестовую заявку.
   Должна прийти в Telegram и появиться в `leads.log`.

## 3. Если лендинг и приёмник на разных доменах

Открой `lead.config.php` и укажи, откуда разрешено отправлять:

```php
'origins' => ['https://домен-лендинга'],
```

По умолчанию стоит `'*'` — работает отовсюду, но тогда чужая страница может
засорять ваш лог.

## Где смотреть заявки

`leads.log` рядом с `lead.php`, по одному JSON на строку:

```json
{"at":"2026-09-16T12:00:00+00:00","name":"Иван Петров","email":"ivan@example.com",
 "lang":"ru","page":"https://lp/?campaign=fb1","ip":"1.2.3.4","flags":[]}
```

```
tail -f leads.log                    # в реальном времени
grep -v '"flags":\[\]' leads.log     # что отсеялось и почему
```

`page` — полный URL со всеми метками, видно, с какой кампании пришёл лид.

`flags` пустой — заявка ушла в Telegram. Иначе:

| флаг | значение |
|---|---|
| `bot` | заполнено скрытое поле-ловушка |
| `no-name`, `bad-email` | не прошла проверку |
| `rate-limited` | больше 6 отправок с одного IP за минуту |

**Важно: заявка пишется в лог раньше, чем что-либо может её отклонить.**
Ни бот, ни флуд, ни упавший Telegram не теряют строку. Telegram — уведомление,
лог — запись.

## Частые проблемы

| симптом | причина |
|---|---|
| форма пишет ошибку, в консоли CORS | не указан `origins`, либо адрес в `config.js` неверный |
| `{"ok":true}`, но в Telegram пусто | пустые `token`/`chat`, либо не нажат Start в чате с ботом |
| в логе пусто | у папки нет прав на запись |
| 500 при открытии `lead.php` | не переименован `lead.config.example.php` |

Проверить бота отдельно от сайта: `source/scripts/check-telegram.mjs`,
запускается `node --env-file=.env.local scripts/check-telegram.mjs`.

## Пересборка лендинга (обычно не требуется)

Нужна, только если меняются тексты или дизайн. Потребуется Node 20+:

```
cd source
npm install
npm run static
```

Результат — папка `dist/` и архив рядом с ней.

## Превью ссылки в мессенджерах (необязательно)

Картинки `og-*.png` лежат рядом со страницей и подключены относительным путём.
Большинство мессенджеров это понимают, но не все. Если нужна гарантия — после
загрузки замените в `index.html` относительный путь на полный:

```
og-en.png  →  https://ваш-домен/og-en.png
```

Страница одна на три языка, поэтому в превью всегда английская карточка.
На платный трафик это не влияет.
